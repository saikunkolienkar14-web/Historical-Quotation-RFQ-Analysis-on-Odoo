Section 2: General Notes / Clarifications

1. Wetted parts
Please note that the we have considered SS 316 as wetted parts for all sampling systems. All components of
sampling system including tubing & fittings are instrumentation components only. For pipe class
RZ109BDRP & RZ309BDRP, we have considered Hastelloy HC276.

2. Units
All valves, tubing & components are in Imperial Units. Pressure gauge unit in kg/cm2g & Temp gauge deg C

3. 3.2 certifications
Since we are using only instrumentation components in our sampling system, 3.2 certs is not available with
none of our sub-vendors. Hence we will only provide 3.1 Material test certificate as per EN 10204. All material
certificates will be made available for review by customer or customer’s appointed 3rd party inspector (TPI)

4. End connections
As per section 4,

5. Sample system component size
As per Dopak standard, all components including valves, tubing and fittings (within the sampling system) will
be 1/4". This will avoid dead volume and help in getting more representative samples.

6. Sample Volume
Sample cylinder size is considered 300cc. Sample bottle size is considered 100cc.

7. Cooler
We have considered Dopak standard shell & tube instrumentation type cooler which is more compact and
highly efficient. For all tags requiring cooler, Dopak standard cooler is offered with sample connection 1/4" and
coolant connection 3/8"F NPT, Cooling coil is considered SS 316 for all tags except the Hastelloy tags for
pipe class RZ109BDRP & RZ309BDRP.

8. Components
All pressure gauges for sample pressure reading are direct mounting type. Also, no DBB is considered for
isolation purposes.

9. Documentation
Documents will consist of the following
a. GA drawings, Dimensional drawings & P&ID
b. Hydrostatic Test Procedure
c. PMI procedure & Test results as per Dopak standard
