SECTION 1: PROJECT OVERVIEW

1. System Description
Adage proposes a complete Oxygen Analyzer System comprising:
•
Four (4) Siemens state-of-the-art Oxygen Analyzers
•
Each analyzer provided with a dedicated Sample Handling System (SHS)
•
All equipment installed inside a purpose-built Analyzer Shelter with HVAC

The system is designed and certified for operation in Hazardous Area Zone 2, Gas Group IIC, Temperature Class
T4.

2. Sample Handling System (SHS)
Each SHS is designed for accurate and reliable oxygen measurement from biogas streams with ~1% moisture
content.

Key Features:
•
Sample Gas Cooler: Removes moisture to protect the analyzer
•
Heated Sample Line (1⁄4" PTFE): Maintains sample above dew point from lagoon tapping to shelter
•
Sample Gas Pump (Zone 2 rated): Ensures flow despite negative process pressure (~–0.5 kPa)
•
Process Connection: Tapping point and counter flange suitable for <3” line size (as per schematic)

Biogas is sourced from two lagoons (two sample points), handled via individual SHS lines.

4. System Safety & Protection
To ensure analyzer longevity and fail-safe operation:
•
Condensate Monitor: Detects any moisture downstream of the gas cooler.
•
Automatic Protection Logic:
o
Shuts down sample pump upon condensate detection.
o
Isolates analyzer via fast loop to prevent wet gas entry.
