SHORT DESCRIPTION OF THE OFFERED SYSTEM 
 
The Ametek Model 931 is a rugged, explosion-proof analyser which is based on the principle of Dual-
wavelength, high-resolution, non-dispersive UV/VIS. It is used for the measurement of H₂S. Its no-moving-
parts, dual-beam, dual-wavelength design uses pulsed UV hollow-cathode lamps and fixed optics—offering 
high resolution (~0.02 nm), excellent linearity across wide ranges, minimal maintenance, and low noise. 
The Sample is extracted using the HAG (Heated Acid Gas) Probe which gently heats the sample, 
preventing condensation in high-dew-point or wet sour gas streams. The heated aspirator within the probe 
circulates the sample via air, nitrogen, or steam, returning excess gas to the process—creating a safe, 
closed-loop system. 
The sample is then transported using a Duplex Tubing arrangement which includes a heated sample line 
plus a sample return line, ensuring smooth circulation, avoiding plugging, and enabling easy maintenance. 
The Calibration Process is done via both zero and span calibration using certified calibration gases. This 
can be done manually or via the automatic calibration feature, which uses an internal solenoid valve system 
to switch between process sample and calibration gas—ensuring traceable, repeatable accuracy without 
dismantling or process interruption.
